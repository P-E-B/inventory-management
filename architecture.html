Request Data Flow

  1. User changes a filter in FilterBar.vue
    Updates global refs: selectedPeriod / selectedLocation / selectedCategory / selectedStatus
  2. View watches filters → calls api.js
    getCurrentFilters() maps UI refs → query params {warehouse, category, status, month}
  3. axios → GET http://localhost:8001/api/...
    Query params appended to URL
  4. FastAPI handler reads in-memory list → apply_filters() / filter_by_month()
    Data sourced from server/data/*.json loaded at startup by mock_data.py
  5. Response validated through Pydantic model → JSON
  6. View stores raw data in ref() → derived UI via computed()
    Charts and tables re-render reactively
